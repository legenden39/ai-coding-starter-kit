# What goes together

Things that belong together: when a new one of the kind arrives, it should also get the same as the others.
The AI reads the list before it calls something new done, and suggests a new line when it sees a pattern. You say yes or no.

Example: "When a new page on the website arrives (e.g. home, about, contact), it also needs: a test, a menu item and a translation." If it matters, lock it with a test that counts, and write the test's path under "Locked by".
