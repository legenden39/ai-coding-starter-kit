# What goes together

Things that belong together: when a new one of the kind arrives, it should also get the same as the others.
The AI reads the list before it calls something new done, and suggests a new line when it sees a pattern. You say yes or no.

Example: "When a new page for a place arrives (cloakroom, bar, table), it also needs: a walkthrough, a menu item and an English text." If it matters, lock it with a test that counts, and write the test's path under "Locked by".
