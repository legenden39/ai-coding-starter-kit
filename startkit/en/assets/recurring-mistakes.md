# Recurring mistakes

Mistakes that have happened more than once. The AI reads the list at the start of every chat.
If you say "that mistake again", the AI writes it in here and suggests a lock.

"Locked by" shows how strongly the mistake is prevented: a hook or a test is strong; "text rule" or "no" is weak and should become a lock. Write the lock's path in backticks (for example `tests/login.test.js`): the proof turns red if the file disappears. If an item has not happened for several months, the AI asks whether it can be removed.
